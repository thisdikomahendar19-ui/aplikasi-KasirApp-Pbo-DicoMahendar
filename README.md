# Aplikasi Kasir - PBO

Aplikasi kasir sederhana berbasis Java dengan NetBeans.

## Fitur
- Input barang dan harga
- Perhitungan total belanja
- Cetak struk pembayaran
- Kembalian otomatis

## Teknologi
- Java
- NetBeans
- Maven

## Cara Menjalankan
1. Clone repository ini
2. Buka di NetBeans
3. Run project
