## ⚡ Cara Cepat Jalankan Aplikasi (Tanpa Install NetBeans)

> Cocok buat dosen atau siapapun yang mau langsung coba tanpa ribet!

### Yang Dibutuhkan
- ✅ **Java JDK/JRE minimal versi 8** — [Download di sini](https://www.oracle.com/java/technologies/downloads/)
- ✅ File **projectdiko1.jar** (ada di folder `dist/` repo ini)

### Langkah-Langkahnya

**1. Pastikan Java sudah terinstall**

Cek dulu di CMD / Terminal:
```
java -version
```
Kalau muncul versi Java berarti sudah oke ✅  
Kalau muncul error, berarti belum ada Java → download dulu di link di atas.

**2. Download file JAR**

- Klik folder `dist/` di repo ini
- Klik file `projectdiko1.jar`
- Klik tombol **Download** (ikon download di kanan atas)

**3. Jalankan Aplikasinya**

**Cara 1 — Double click** file `projectdiko1.jar` langsung  

**Cara 2 — Lewat CMD** (kalau double click tidak jalan):
```
java -jar projectdiko1.jar
```

## 🛠️ Cara Buka & Edit di NetBeans (Untuk Developer)

Kalau mau lihat atau edit source code-nya:

**Yang Dibutuhkan:**
- Java JDK 8 atau lebih baru
- NetBeans IDE — [Download di sini](https://netbeans.apache.org/front/main/download/)

**Langkah-Langkahnya:**
1. Clone repo ini:
```
git clone https://github.com/thisdikomahendar19-ui/aplikasi-KasirApp-Pbo-DicoMahendar.git
```
2. Buka NetBeans
3. Klik **File → Open Project**
4. Arahkan ke folder hasil clone tadi
5. Klik **Run Project** (tombol ▶️ hijau) atau tekan `F6`
6. untuk password dan usernya admin/admin123
